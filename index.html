Palimpsest

Read along to the audiobook. The spoken word stays glued to the page.

iPhone & iPad

Requires iOS 17 or later.

Join the TestFlight beta
  1. Install TestFlight from the App Store.
  2. Tap the invitation link above on your iPhone or iPad.
  3. Open the Palimpsest beta and import an audiobook + EPUB.

App Store listing coming soon.

Mac

Requires macOS 14 (Sonoma) or later. Apple Silicon and Intel.

Join the TestFlight beta
  1. Palimpsest ships as a Mac Catalyst build — the same TestFlight invitation works on Mac.
  2. Install TestFlight for Mac.
  3. Open the invitation link, then install from TestFlight.

Mac App Store listing arrives alongside the iOS App Store release.

Android

Requires Android 8.0 (Oreo) or later. ARM64, ARMv7, x86_64.

Google Play — coming soon Download APK directly
  1. Download the .apk to your phone.
  2. Open it; allow installs from your browser when prompted.
  3. Launch Palimpsest and grant audio storage permission so the player can find your audiobooks.

Windows

Requires Windows 10 (1903+) or Windows 11. x64 and ARM64.

Download installer
  1. Install ffmpeg (winget install Gyan.FFmpeg).
  2. Run the Palimpsest installer.
  3. Launch from Start; import an audiobook + EPUB from File → Import.

First public build pending Microsoft Store review.

Linux

Tested on Ubuntu 22.04+ and Debian 12+. Other distros should work with the same runtime deps.

Download AppImage
  1. Install runtime deps: 
    sudo apt install ffmpeg libmpv2 libgtk-3-0
  2. Make the AppImage executable and run: 
    chmod +x Palimpsest-*.AppImage
./Palimpsest-*.AppImage
Build from source 
git clone https://github.com/rRexhepi/Palimpsest.git
cd Palimpsest/xplatform
bash scripts/setup-linux-vm.sh
flutter pub get
flutter build linux --release
./build/linux/x64/release/bundle/palimpsest
