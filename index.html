Palimpsest

Audiobook and ebook sync reader.

iPhone and iPad

iOS 17 or later.

Join the TestFlight beta.

  1. Install TestFlight from the App Store.
  2. Tap the invitation link above.
  3. Open the Palimpsest beta and import an audiobook plus an ebook (.epub, .mobi, or .pdf).

App Store listing coming soon.

Mac

macOS 14 or later. Apple silicon and Intel.

Join the TestFlight beta.

  1. Palimpsest runs as a Mac Catalyst build. The same TestFlight invite covers Mac.
  2. Install TestFlight for Mac.
  3. Open the invitation link, then install from TestFlight.
  4. Import an audiobook plus an ebook (.epub, .mobi, or .pdf).

Mac App Store listing arrives with the iOS App Store release.

Android

Android 8.0 or later.

Recommended — arm64

Any phone made in the last seven years or so. If you're not sure which architecture your device is, it's this one.

Download palimpsest-0.1.0-android-arm64-v8a.apk (61 MB)

Older 32-bit ARM

For budget or pre-2017 devices that don't support arm64.

Download palimpsest-0.1.0-android-armeabi-v7a.apk (50 MB)

x86_64

Android emulators and the few Chromebooks that run Android apps natively.

Download palimpsest-0.1.0-android-x86_64.apk (69 MB)

Install

  1. Download the .apk on your phone.
  2. Open it. Android will ask once to allow installs from the app you downloaded with (usually Chrome or your file manager).
  3. Launch Palimpsest and import an audiobook + ebook.

Updates: there's no auto-update without Play Store. Obtainium can watch this page's GitHub releases and prompt for updates the way Play Store does — paste the repo URL https://github.com/rRexhepi/palimpsest-app into Obtainium to subscribe.

Google Play listing is on the roadmap.

Windows

Windows 10 1903 or later. x64 and ARM64.

Download palimpsest-0.1.0-windows-x64.exe

  1. Install ffmpeg with winget install Gyan.FFmpeg.
  2. Run the Palimpsest installer.
  3. Launch Palimpsest from the Start menu and import an audiobook + ebook.

Microsoft Store listing on the roadmap.

Linux

Ubuntu 22.04+, Debian 12+, Pop!_OS, Mint. x86_64.

Two builds. Both ship the same binary; the difference is whether Calibre is pulled in as a dependency.

Lite — recommended for most

EPUB + MOBI import, audiobook + sync. ~80 MB installed. No Calibre.

Download palimpsest_0.1.0_amd64.deb

sudo apt install ./palimpsest_0.1.0_amd64.deb

Full — every format

Adds Calibre as a hard dependency so PDF, AZW3, RTF, DOCX, LIT, FB2 and the rest import out of the box. ~620 MB installed (Calibre brings Python + Qt + WebEngine).

Download palimpsest-full_0.1.0_amd64.deb

sudo apt install ./palimpsest-full_0.1.0_amd64.deb

Launch from your app menu (search "Palimpsest") or run palimpsest from a terminal. The lite build can pick up Calibre later with sudo apt install calibre.

Other distros: a Flatpak / AppImage build is on the roadmap. For now, build from source.

Build from source 
git clone https://github.com/rRexhepi/Palimpsest.git
cd Palimpsest/xplatform
flutter pub get
flutter build linux --release
./build/linux/x64/release/bundle/palimpsest
